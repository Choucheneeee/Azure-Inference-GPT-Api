# Azure AI Inference Chat Server

A lightweight Express.js server for handling chat completions using Azure's AI Inference service.

## Features
- Chat completion API endpoint
- Health check endpoint
- Environment variable configuration
- Error handling and CORS support

## Technologies
- Express.js
- Azure AI Inference SDK
- CORS middleware
- Dotenv for environment management

## Prerequisites
- Node.js v18+
- Azure account with AI Inference access
- Azure endpoint, model, and API token

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/REPO_NAME.git
   cd REPO_NAME

     ```bash
     TOKEN="your_azure_api_token"
